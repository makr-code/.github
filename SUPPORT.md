# Support

For community questions and help, search existing discussions and issues in the affected repository first.

If you still need help, open an issue at [makr-code community support](https://github.com/makr-code/.github/issues). Identify the affected repository, describe your goal and what happened, and share a minimal example when useful.

Public issues are visible to everyone. Do not include confidential data, credentials, personal information, or private logs. Remove sensitive information from examples and attachments.

Use the affected repository's issue forms for bugs and feature requests. For vulnerabilities, follow [Security](SECURITY.md) instead of posting publicly. Community support has no guaranteed response time.
