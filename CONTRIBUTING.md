# Contributing

Contributions are welcome across makr-code repositories. Follow any repository-specific instructions and the [Code of Conduct](CODE_OF_CONDUCT.md).

- Search existing issues and pull requests before opening a new one.
- Use the issue forms for bugs and feature ideas. Discuss larger changes before investing substantial work.
- Keep changes focused, explain their purpose, and update related documentation.
- Validate changes using the affected repository's documented checks when available. In your pull request, describe what you checked and any limitations.
- Do not include credentials, personal information, or confidential material in issues, pull requests, logs, or examples.

For questions, see [Support](SUPPORT.md). Report vulnerabilities through the private guidance in [Security](SECURITY.md), not public issues.
