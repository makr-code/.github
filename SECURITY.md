# Security

Report suspected vulnerabilities privately in the affected repository. Follow its repository-specific security policy when present.

1. In the affected repository, open **Security > Report a vulnerability** when that option is enabled.
2. If that option is unavailable, use an explicitly documented private reporting channel.
3. If no private channel is available, do not post exploit details, secrets, or the vulnerability publicly. Ask @makr-code only for a private reporting channel, without any details.

Once a private channel is established, describe the affected repository and version, the impact, and minimal reproduction steps. Do not send live credentials or unnecessary personal data.

Allow maintainers time to assess the report and coordinate a fix before public disclosure. Supported versions and remediation plans depend on the affected repository; no response or fix timeline is guaranteed.
